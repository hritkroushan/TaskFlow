# TaskFlow

A modern, intuitive task management application designed to help teams and individuals organize, track, and complete their work efficiently.

## Features

- **Task Management**: Create, update, and organize tasks with ease
- **Priority Levels**: Set task priorities to focus on what matters most
- **Due Dates**: Track deadlines and stay on schedule
- **Collaboration**: Share tasks and collaborate with team members
- **Real-time Updates**: See changes instantly across all devices
- **Progress Tracking**: Monitor task completion and project progress
- **Notifications**: Get reminders for upcoming deadlines and task updates
- **Dark Mode**: Comfortable viewing in any lighting condition

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/hritkroushan/TaskFlow.git
cd TaskFlow
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The application will open in your default browser at `http://localhost:3000`

## Usage

### Creating a Task

1. Click the "+" button or "New Task" option
2. Enter the task title and description
3. Set priority level (Low, Medium, High)
4. Assign a due date if needed
5. Click "Save" to create the task

### Managing Tasks

- **Edit**: Click on a task to edit its details
- **Complete**: Mark tasks as done with the checkbox
- **Delete**: Remove tasks you no longer need
- **Filter**: Sort tasks by priority, due date, or status
- **Search**: Quickly find tasks using keywords
